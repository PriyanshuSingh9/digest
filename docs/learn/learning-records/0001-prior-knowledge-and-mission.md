# Initial Baseline: Starting Tauri v2 for Digest Engine

The user wants to understand the inner workings and architecture of Tauri v2 to develop the `digest` local-first desktop application. The project uses React 19 + TypeScript on Vite for the frontend and Rust for the Tauri backend. We established a curriculum focused on process architecture, IPC invoke commands, event streaming for timeline synchronization, state management, and the v2 capability/permission system.

## Implications
- Start with the core process model and IPC mechanism (Lesson 0001).
- Subsequent lessons will progress directly to writing custom commands, error handling, state management, and real-time event streaming for the audio/presentation runtime.
