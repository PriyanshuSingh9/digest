1. Process Model & IPC Primitives

Pattern Flow Direction Protocol / Type Digest Engine Use Case
Command (`invoke`) Frontend ➔ Rust (Req / Res) JSON-RPC Async Promise Trigger article parsing, load files, start audio generation
Event (`emit` / `listen`) Rust ➔ Frontend (Pub / Sub) Streaming / One-way Push Audio playback progress clock, timeline step updates
State (`tauri::State`) Rust Core internal Type-safe DI via `manage()` Active presentation session, audio engine handle, cache

2. Command Signatures Cheat Sheet

Frontend (TypeScript)

import { invoke } from "@tauri-apps/api/core";

// 1. Simple invoke
const greeting = await invoke<string>("greet", {
  name: "Learner"
});

// 2. Invoking with custom error handling
try {
  const result = await invoke<ArticleData>("parse_article", {
    url: "https://example.com/post"
  });
} catch (err) {
  console.error("Rust error:", err);
}

Backend (Rust - `src-tauri/src/lib.rs`)

// 1. Basic command
#[tauri::command]
fn greet(name: &str) -> String {
    format!("Hello, {}!", name)
}

// 2. Command returning Result (Error handling)
#[tauri::command]
async fn parse_article(url: String) -> Result<ArticleData, String> {
    if !url.starts_with("http") {
        return Err("Invalid URL scheme".into());
    }
    Ok(ArticleData::from_url(&url).await)
}

3. State Injection in Commands

use std::sync::Mutex;
use tauri::State;

struct AudioEngineState {
    current_timestamp_ms: Mutex<u64>,
}

#[tauri::command]
fn update_timeline_clock(
    new_time: u64,
    state: State<'_, AudioEngineState>
) -> Result<u64, String> {
    let mut clock = state.current_timestamp_ms.lock().unwrap();
    *clock = new_time;
    Ok(*clock)
}
